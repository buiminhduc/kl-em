# AI collaboration log

Factual record of how the AI assistant was directed on this take-home. Dates are 2026.

| 28–29 Oct | The AI's first concurrency proposal used pessimistic `SELECT … FOR UPDATE`. It was replaced by optimistic insert with retry on `23P01`, with exclusion constraints as the lock, because `FOR UPDATE` cannot lock rows that do not exist yet (the phantom problem). |
| 28–29 Oct | Đức decided the open assumptions: 15-minute turnaround buffer per dealership, preferred technician as a soft preference, dealership opening hours only (no technician shifts), and keeping the vehicle exclusion constraint beyond the brief. |

The AI had to change the default port twice after finding 3000–3006 already in use on the Mac, and to run Jest with `--experimental-vm-modules` for ESM-only dependencies. |

Dev and test databases were recreated and migrated from scratch; unit 2/2 and integration 8/8 passed, `down` then `up` succeeded. |

Verified: unit 19/19, integration 21/21 (including 20 parallel posts → exactly one 201), lint and build clean, curl against a spare port (3110) while Đức's dev server kept running on 3100. |
